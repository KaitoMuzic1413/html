Tổng quan về CSS

Khái niệm: CSS (Cascading Style Sheets) là ngôn ngữ định kiểu dùng để thiết kế, trang trí và định dạng giao diện cho các tài liệu viết bằng HTML.

Công dụng: Giúp tách biệt hoàn toàn phần cấu trúc nội dung (HTML) khỏi phần trình bày giao diện (màu sắc, bố cục, hiệu ứng), giúp mã nguồn dễ bảo trì và tái sử dụng.

Làm được gì & Không làm được gì:

  • Làm được: Trang trí giao diện, tạo hiệu ứng chuyển động mượt mà, bố trí lưới linh hoạt (Flexbox/Grid), hỗ trợ hiển thị tốt trên mọi thiết bị (Responsive).
  • Không làm được: Không xử lý logic lập trình, không tự tương tác dữ liệu động từ người dùng (cần JavaScript) và không tạo ra các thẻ nội dung thô (cần HTML).

Code mẫu cấu trúc CSS:

CSS
/* Cấu trúc quy tắc CSS */
selector {
    property: value;
}

Output:

(Quy tắc định kiểu giao diện áp dụng lên phần tử)

3 cách sử dụng CSS

Khái niệm: Các phương pháp tích hợp mã CSS vào trang HTML.

Công dụng: Cho phép áp dụng kiểu dáng linh hoạt từ cục bộ đến toàn cục.

  • Inline CSS: Viết trực tiếp vào thuộc tính style của thẻ HTML.
  • Internal CSS: Viết bên trong thẻ <style> tại phần <head> của trang.
  • External CSS: Viết trong file .css riêng biệt và liên kết vào HTML qua thẻ <link>.

Code:

HTML / CSS
<!-- External CSS link -->
<link rel="stylesheet" href="style.css">

<!-- Internal CSS -->
<style>
    body { background-color: #000; }
</style>

<!-- Inline CSS -->
<p style="color: cyan;">Nội dung</p>

Output:

Nội dung hiển thị với inline CSS

Cascade, Inheritance & Specificity

Khái niệm: Quy tắc độ ưu tiên (Specificity), tính kế thừa (Inheritance) và thứ tự đè lớp (Cascade) trong CSS.

Công dụng: Xác định chính xác thuộc tính nào sẽ được trình duyệt ưu tiên áp dụng khi có nhiều quy tắc xung đột.

  • Specificity (Độ ưu tiên): Inline (1000) > ID (#id = 100) > Class/Pseudo-class (.class = 10) > Element (tag = 1).
  • Inheritance (Kế thừa): Một số thuộc tính văn bản (color, font-family) tự động truyền từ thẻ cha xuống thẻ con.

Code:

CSS
p { color: white; }        /* Độ ưu tiên thấp */
.special { color: yellow; } /* Độ ưu tiên trung bình */
#main { color: cyan; }      /* Độ ưu tiên cao nhất */

Output:

Đoạn văn này chịu chi phối bởi độ ưu tiên ID (#main)

Selectors cơ bản

Công dụng: Khoanh vùng đối tượng từ rộng đến hẹp.

Code:

CSS

div { background: #111; padding: 10px; }
.my-class { color: #00ffff; }
#my-id { border: 1px solid #444; }

Nội dung bên trong bộ chọn cơ bản

Combinators (Bộ kết hợp Selector)

Khái niệm: Quan hệ giữa các selector (Descendant A B, Child A > B, Adjacent sibling A + B, General sibling A ~ B).

Công dụng: Chọn phần tử dựa trên vị trí cấu trúc phân cấp của chúng.

Code:

CSS
/* Child selector */
.parent > p {
    color: #10b981;
}

Output:

Đoạn văn con trực tiếp (Child)

Attribute Selectors

Khái niệm: Chọn phần tử dựa vào sự xuất hiện của thuộc tính HTML (ví dụ: [disabled], [type="text"]).

Công dụng: Định kiểu linh hoạt cho các trường input hoặc liên kết có thuộc tính đặc thù.

Code:

CSS
input[type="text"] {
    background-color: #1e293b;
    color: white;
    padding: 5px;
    border: 1px solid #475569;
}

Công dụng: Thay đổi kiểu dáng khi người dùng tương tác hoặc theo vị trí con.

Code:

CSS

Pseudo-elements

Khái niệm: Tạo hoặc định dạng một phần nhỏ của phần tử (như ::before, ::after, ::placeholder, ::selection).

Công dụng: Trang trí, thêm icon hoặc định dạng ký tự đầu dòng mà không cần thêm thẻ HTML thừa.

Code:

CSS

Thuộc tính display: inline (Hạn chế)

Khái niệm: Hiển thị nối tiếp trên cùng một dòng, chỉ chiếm không gian bằng nội dung bên trong.

Làm được & Không làm được:

  • Làm được: Đổi màu chữ, màu nền, padding/margin ngang.
  • Không làm được: Không chỉnh được width và height, margin dọc bị vô hiệu hóa.

Code minh họa (Chỉnh width thất bại):

CSS
span.bad-inline {
    display: inline;
    width: 400px;   /* Bị vô tác dụng! */
    height: 100px;  /* Bị vô tác dụng! */
    background: #ef4444;
}

Output:

Đoạn văn chứa thẻ span inline không thay đổi kích thước khi gán width/height.

Đơn vị đo lường trong CSS

Code:

CSS

Responsive Design & Media Queries

Khái niệm: Kỹ thuật điều chỉnh giao diện thích ứng với mọi kích thước thiết bị thông qua @media (max-width: ...).

Code:

CSS
@media (max-width: 768px) {
    body {
        background-color: #111;
    }
}

Transitions & Transforms

Khái niệm: Tạo hiệu ứng chuyển động mượt mà (transition) và biến đổi hình học 2D/3D (transform).

Code:

CSS
.btn-anim {
    transition: transform 0.3s ease, background-color 0.3s;
}
.btn-anim:hover {
    transform: scale(1.05);
    background-color: #00ffff;
    color: black;
}

CSS
