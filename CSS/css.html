Tổng quan về CSS

Khái niệm: CSS (Cascading Style Sheets) là ngôn ngữ định kiểu dùng để thiết kế giao diện web.

Code mẫu (External Approach):

index.html (Liên kết file style.css bên ngoài)
<!DOCTYPE html>
<html lang="vi">
<head>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <div class="box">Nội dung mẫu</div>
</body>
</html>
style.css (File CSS riêng biệt)
.box {
    background: #1e293b;
    color: #38bdf8;
    padding: 15px;
    border-radius: 8px;
}

Output:

Nội dung mẫu áp dụng External CSS

3 cách sử dụng CSS

Lý thuyết: Gồm Inline (trong thẻ), Internal (trong thẻ <style>), và External (file .css riêng - Khuyên dùng).

Code mẫu:

index.html
<link rel="stylesheet" href="style.css">
<p class="text-external">Đoạn văn dùng External CSS</p>
style.css
.text-external {
    color: #06b6d4;
    font-weight: bold;
    font-size: 16px;
}

Output:

Đoạn văn dùng External CSS

Cú pháp & Selector cơ bản

Lý thuyết: Cấu trúc gồm Selector và khối khai báo thuộc tính: giá trị.

Code mẫu:

index.html
<h3 class="title-demo">Tiêu đề Demo</h3>
style.css
.title-demo {
    color: #7c3aed;
    border-left: 4px solid #7c3aed;
    padding-left: 8px;
}

Output:

Tiêu đề Demo

Cascade, Inheritance & Specificity

Lý thuyết: Quy tắc độ ưu tiên khi đè lớp: Inline (1000) > ID (100) > Class (10) > Element (1).

Code mẫu:

index.html
<p id="text-id" class="text-cls">Văn bản kiểm tra độ ưu tiên</p>
style.css
p { color: gray; }
.text-cls { color: green; }
#text-id { color: #2563eb; } /* Thắng thế do ID cao điểm hơn */

Output:

Văn bản kiểm tra độ ưu tiên

Selectors cơ bản

Lý thuyết: Vạn năng (*), thẻ (tag), class (.class), ID (#id).

Code mẫu:

index.html
<div class="box-card">Hộp nội dung thẻ div</div>
style.css
.box-card {
    background: #e2e8f0;
    color: #1e293b;
    padding: 12px;
    border-radius: 8px;
}

Output:

Hộp nội dung thẻ div

Combinators (Bộ kết hợp Selector)

Lý thuyết: Descendant (A B), Child (A > B), Adjacent (A + B), General (A ~ B).

Code mẫu:

index.html
<div class="parent-box">
    <p>Đoạn văn con trực tiếp</p>
</div>
style.css
.parent-box > p {
    color: #dc2626;
    font-weight: bold;
}

Output:

Đoạn văn con trực tiếp

Attribute Selectors

Lý thuyết: Chọn phần tử theo thuộc tính HTML: [attr], [attr="val"], [attr^="val"].

Code mẫu:

index.html
<input type="text" value="Ô input dạng text">
style.css
input[type="text"] {
    border: 2px solid #0284c7;
    padding: 6px 12px;
    border-radius: 6px;
}

Output:

Pseudo-classes

Lý thuyết: Trạng thái phần tử như :hover, :focus, :active, :nth-child().

Code mẫu:

index.html
<button class="btn-state">Rê chuột vào tôi</button>
style.css
.btn-state {
    padding: 10px 20px;
    background: #334155;
    color: white;
    border: none;
    border-radius: 6px;
    cursor: pointer;
}
.btn-state:hover {
    background: #7c3aed;
}

Output:

Pseudo-elements

Lý thuyết: Tạo thành phần ảo qua ::before, ::after, ::first-letter.

Code mẫu:

index.html
<p class="note-text">Nội dung thông báo quan trọng.</p>
style.css
.note-text::before {
    content: "Lưu ý: ";
    color: #eab308;
    font-weight: bold;
}

Output:

Lưu ý: Nội dung thông báo quan trọng.

Màu sắc & Background (Full thuộc tính & giá trị)

Thuộc tính & Giá trị: color, background-color, background-image (linear-gradient), background-size (cover/contain), background-repeat (no-repeat), background-position (center).

Code mẫu:

index.html
<div class="bg-demo">Nền Gradient & Background</div>
style.css
.bg-demo {
    background: linear-gradient(135deg, #3b82f6, #9333ea);
    background-repeat: no-repeat;
    background-size: cover;
    color: white;
    padding: 20px;
    border-radius: 10px;
    text-align: center;
}

Output:

Nền Gradient & Background

Typography (Kiểu chữ - Full thuộc tính & giá trị)

Thuộc tính & Giá trị: font-family, font-size (px/rem), font-weight (100-900/bold), font-style (italic), text-transform (uppercase), letter-spacing.

Code mẫu:

index.html
<p class="typo-demo">Văn bản định dạng Typography</p>
style.css
.typo-demo {
    font-family: Arial, sans-serif;
    font-size: 18px;
    font-weight: 700;
    text-transform: uppercase;
    letter-spacing: 2px;
    color: #4f46e5;
}

Output:

Văn bản định dạng Typography

CSS Grid Layout

Lý thuyết: display: grid, grid-template-columns, gap.

Code mẫu:

index.html
<div class="grid-box">
    <div class="g-item">1</div>
    <div class="g-item">2</div>
    <div class="g-item">3</div>
</div>
style.css
.grid-box {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 10px;
}
.g-item {
    background: #8b5cf6;
    color: white;
    padding: 15px;
    text-align: center;
    border-radius: 6px;
}

1
2
3

    border-radius: 6px;
}

Output:

Hộp sử dụng hàm calc()

Responsive Design & Media Queries

Lý thuyết: @media (max-width: ...).

Code mẫu:

index.html
<p>Nội dung tự thích ứng thiết bị</p>
style.css
@media (max-width: 768px) {
    body { font-size: 14px; }
}

Output:

(Giao diện tự động thay đổi theo kích thước màn hình)

Transitions & Transforms

Lý thuyết: transition kết hợp transform: scale() | rotate().

Code mẫu:

index.html
<button class="trans-btn">Rê chuột phóng to</button>
style.css
.trans-btn {
    transition: transform 0.3s ease, background-color 0.3s;
    background: #334155;
    color: white;
    padding: 10px 20px;
    border: none;
    border-radius: 6px;
    cursor: pointer;
}
.trans-btn:hover {
    transform: scale(1.08);
    background: #06b6d4;
    color: black;
}

Output:

CSS Animations & Keyframes

Lý thuyết: @keyframes kết hợp animation.

Code mẫu:

index.html
<div class="anim-dot"></div>
style.css
@keyframes bounce {
    0%, 100% { transform: translateY(0); }
    50% { transform: translateY(-10px); }
}
.anim-dot {
    width: 30px;
    height: 30px;
    background: #06b6d4;
    border-radius: 50%;
    animation: bounce 1s infinite ease-in-out;
}

Output:

CSS Variables & Themes

Lý thuyết: :root { --name: value; } và var(--name).

Code mẫu:

index.html
<p class="var-text">Văn bản dùng biến CSS toàn cục</p>
style.css
:root {
    --accent-color: #a78bfa;
}
.var-text {
    color: var(--accent-color);
    font-weight: bold;
}

Output:

Văn bản dùng biến CSS toàn cục

Advanced CSS & @layer

Lý thuyết: Cascade Layers (@layer) kiểm soát độ ưu tiên.

Code mẫu:

index.html
<div class="modern-card">Thẻ Card phong cách CSS hiện đại</div>
style.css
@layer components {
    .modern-card {
        background: #1e293b;
        padding: 15px;
        border-radius: 8px;
        border: 1px solid #334155;
        color: #fff;
    }
}

Output:

Thẻ Card phong cách CSS hiện đại
